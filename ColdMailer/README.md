# Service for Sendmail with AI 🚀

MVP сервис для холодных рассылок с защитой от спам-фильтров и поддержкой персонализации.

## Структура проекта
- `config.py` — настройки SMTP сервера и пауз.
- `leads.csv` — база контактов (email, name, company, status).
- `sender.py` — асинхронный скрипт рассылки с сохранением статусов и случайными задержками.

## Быстрый запуск
1. Заполните `config.py` своими данными SMTP.
2. Добавьте лидов в `leads.csv`.
3. Запустите скрипт:
```bash
python sender.py
```
