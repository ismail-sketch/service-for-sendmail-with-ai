# ColdMailer 🚀

Веб-панель для холодных email-рассылок с защитой от спам-фильтров.
Локальный сервис: всё работает у вас на компьютере, ничего не уходит наружу.

## Возможности
- 🖥 Веб-интерфейс (открывается в браузере на `http://127.0.0.1:5000`)
- ✉️ Настройка SMTP прямо в форме — без правки кода
- 📇 Загрузка базы контактов из CSV (email, name, company, status)
- 🎯 Персонализация писем: `{{name}}`, `{{company}}`, `{{email}}`, `{{sender_name}}`
- ⏱ Рандомные паузы между письмами (анти-спам)
- 📊 Живой прогресс рассылки и статусы (отправлено / ошибка / ожидает)
- 🔁 Автопометка отправленных — повторно письмо не уйдёт
- ✅ Кнопка проверки SMTP-соединения

## Быстрый запуск
1. Установите Python 3.10+.
2. Дважды щёлкните по `run.bat` — зависимости подтянутся сами, и в браузере откроется панель.

Или вручную:
```bash
pip install -r requirements.txt
python app.py
```
Затем откройте http://127.0.0.1:5000

## Как пользоваться
1. Вкладка **«Настройки»** — впишите SMTP-данные и текст письма. Нажмите **«Сохранить»**.
2. Вкладка **«Контакты»** — загрузите CSV-файл с лидами.
3. Вкладка **«Рассылка»** — нажмите **«Проверить SMTP-соединение»**, затем **«Запустить рассылку»**.

## Пароль приложения
Для Gmail / Яндекс / Mail.ru нельзя использовать обычный пароль от почты.
Нужно создать **«пароль приложения»** в настройках безопасности почтового аккаунта.

## Структура
- `app.py` — Flask-сервер и логика рассылки
- `templates/index.html` — веб-интерфейс
- `settings.json` — настройки (создаются автоматически при сохранении)
- `leads.csv` — база контактов
- `run.bat` — запуск в один клик
