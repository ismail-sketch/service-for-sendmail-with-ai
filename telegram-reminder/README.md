# Telegram-напоминалка с «пониманием» естественного языка

Бот, которому пишешь обычным языком — «напомни позвонить маме завтра в 18:00» или
«напомни 5 числа вечером купить билеты» — а он присылает напоминание в Telegram в нужный момент.

## Как это устроено

```
Ты пишешь боту  ──▶  LLM разбирает: текст + дата/время  ──▶  сохранение в SQLite
                                                                        │
        Напоминание в Telegram  ◀──  планировщик каждые 20 сек проверяет  ◀──┘
```

Файлы:
- `bot.py` — обработка сообщений Telegram и планировщик
- `llm.py` — разбор естественного языка через LLM (OpenAI-совместимый API)
- `storage.py` — база данных SQLite
- `config.py` — настройки из `.env`

---

## Шаг 1. Установить зависимости

```bash
pip install -r requirements.txt
```

---

## Шаг 2. Создать бота в Telegram

1. В Telegram открой `@BotFather` (поиск в контактах).
2. Отправь команду `/newbot`.
3. Придумай имя и username бота (username должен заканчиваться на `bot`, например `moy_napominalka_bot`).
4. BotFather пришлёт **токен** вида `123456789:AAE...`. Скопируй его.

---

## Шаг 3. Получить ключ LLM

Выбери провайдера (оба совместимы):

| Провайдер | Где взять ключ | Строки в `.env` |
|---|---|---|
| **OpenAI** | platform.openai.com → API keys | `LLM_BASE_URL=https://api.openai.com/v1`, `LLM_MODEL=gpt-4o-mini` |
| **DeepSeek** | platform.deepseek.com → API keys | `LLM_BASE_URL=https://api.deepseek.com`, `LLM_MODEL=deepseek-chat` |
| **OpenRouter** | openrouter.ai → Keys (много моделей) | `LLM_BASE_URL=https://openrouter.ai/api/v1`, `LLM_MODEL=<любая>` |

---

## Шаг 4. Настроить `.env`

1. Скопируй файл `.env.example` в `.env`:
   ```bash
   copy .env.example .env
   ```
2. Открой `.env` в блокноте и заполни:
   ```ini
   BOT_TOKEN=123456789:AAE...   # токен из BotFather
   LLM_API_KEY=sk-...          # ключ LLM
   LLM_BASE_URL=https://api.openai.com/v1
   LLM_MODEL=gpt-4o-mini
   TIMEZONE=Europe/Moscow      # твой часовой пояс
   ```

---

## Шаг 5. Запустить бота

```bash
python bot.py
```

Открой своего бота в Telegram, нажми `/start` и напиши, например:
> Напомни позвонить маме завтра в 18:00

Бот ответит, что запомнил (и покажет, как понял время), а в 18:00 пришлёт напоминание.

### Команды
- `/list` — показать активные напоминания
- `/del <номер>` — удалить напоминание (номер виден в `/list`)

---

## ⚠️ Важно: бот должен работать постоянно

Пока скрипт запущен и компьютер не спит — напоминания приходят. Если закрыть окно
консоли или выключить ПК — напоминание не уйдёт.

Рекомендации для Windows:
- Отключи «сон» в параметрах электропитания, пока бот нужен.
- Чтобы бот работал даже после перезагрузки — добавь `python bot.py` в
  **Планировщик заданий** (taskschd.msc → «Создать задачу» → триггер «При входе в систему»).

### Перенос на VPS (когда решишь)
Ничего менять не нужно — просто скопируй папку на сервер, поставь зависимости и запусти
`python bot.py` под `systemd`/`pm2`/`supervisor`. База `reminders.db` переезжает вместе с папкой.

---

## Если не хочешь платить за LLM

Можно заменить разбор времени на бесплатную локальную библиотеку `dateparser`
(понимает «завтра в 18:00», «через час», «5 числа», но хуже на сложных фразах).
Скажи — подключу вместо `llm.py`.
